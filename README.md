# Dashboard de Avaliações — Atualizado

Este pacote contém o dashboard atualizado com os dados do arquivo Comentários(2).xlsx.

## Base utilizada

- Cristo Redentor: 999 avaliações
- Bondinho: 50 avaliações
- Total: 1.049 avaliações

## Publicação no GitHub Pages

1. Substitua o arquivo `index.html` antigo por este.
2. Faça o commit e envie para o GitHub.
3. O GitHub Pages atualizará o dashboard após a publicação do novo commit.
